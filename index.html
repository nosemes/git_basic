1. Crear el repositori a GitHub

1 Crear el repositori

Entra a GitHub i crea un repositori nou. Assigna-li un nom, per exemple tinkercad.

https://github.com/nosemes/tinkercad.git

Aquesta adreça és un exemple: fes servir la URL del teu propi repositori.

2. Preparar el repositori a l'ordinador

2 Clonar el repositori

Obre el terminal a la carpeta on vols desar el projecte. La comanda crea una carpeta local amb el repositori.

git clone https://github.com/nosemes/tinkercad.git

3 Entrar a la carpeta del projecte

Situa't dins la carpeta clonada abans de continuar.

cd tinkercad

4 Configurar la identitat de Git

Indica el nom i el correu que figuraran als commits. Amb --global la configuració s'aplica als repositoris de l'usuari.

git config --global user.name "El teu nom"
git config --global user.email "correu@exemple.cat"

3. Treballar i publicar canvis

5 Modificar els arxius

Crea o edita els arxius del projecte dins la carpeta clonada. Després prepara els canvis per al commit.

git add .

6 Crear un commit

Desa una versió dels canvis preparats amb un missatge descriptiu.

git commit -m "Primera versió del projecte"

7 Enviar els commits a GitHub

Publica els commits locals a la branca main del repositori remot.

git push -u origin main

El cicle habitual:

Modificar arxius→git add .→git commit→git push
Després del primer push, normalment n'hi ha prou amb git push.

4. Consultar commits i visitar versions anteriors

Un commit és una fotografia dels arxius versionats en un moment concret. El HASH és l'identificador del commit.

git log --oneline

Exemple d'historial:

a3f52d1  Tercer commit
b7e91c2  Segon commit
c4d82a0  Primer commit

8 Visitar un commit anterior

La carpeta recupera l'estat dels arxius versionats d'aquell commit, sense moure la branca main. Els arxius afegits en commits posteriors deixen d'aparèixer temporalment.

git switch --detach c4d82a0

9 Visitar un altre commit

Podem anar a qualsevol altre commit utilitzant el seu identificador.

git switch --detach b7e91c2

10 Tornar a la versió actual

Torna a la branca main i recupera l'estat actual dels arxius versionats.

git switch main
Abans de canviar de commit, comprova amb git status que no hi ha canvis pendents. Els arxius no versionats normalment no desapareixen; Git pot impedir el canvi si hi ha conflictes.

5. Taula de consulta ràpida

ComandaFunció
git statusMostra l'estat del repositori i la branca actual.
git log --onelineMostra els commits amb l'identificador abreujat.
git switch --detach HASHVisita l'estat dels arxius d'un commit sense moure main.
git switch mainTorna a la branca principal i als seus arxius actuals.
git add .Prepara els canvis per al proper commit.
git commit -m "Missatge"Crea un commit amb els canvis preparats.
git pushEnvia els commits locals al repositori remot.
Contingut complementari

Annex · Recuperació i historial avançat

Aquestes comandes són complementàries. Per visitar versions anteriors sense alterar main, és preferible git switch --detach.

A. git reset --hard HASH

Mou la branca actual al commit indicat i fa coincidir els arxius versionats amb aquella versió. Descarta els canvis locals no confirmats dels arxius versionats.

git reset --hard c4d82a0

Si main apuntava al tercer commit, després del reset passarà a apuntar al primer. Els commits posteriors deixaran de sortir a git log des de main, però poden continuar existint temporalment.

B. git reflog

Mostra els moviments recents de HEAD i ajuda a localitzar commits anteriors, inclosos els que han deixat d'aparèixer a l'historial de main després d'un reset.

git reflog

Si el tercer commit encara és recuperable, pots tornar-hi amb el seu HASH:

git reset --hard a3f52d1
Atenció: els commits sense cap referència no es conserven necessàriament per sempre. Si els commits ja s'han compartit a GitHub, reescriure l'historial pot afectar altres persones.

C. Diferència essencial

ComandaQuè fa?
git switch --detach HASHVisita un commit; no mou la branca main.
git reset --hard HASHMou la branca actual al commit i descarta canvis locals versionats no confirmats.
git reflogPermet trobar posicions anteriors de HEAD per recuperar commits mentre encara existeixin.
Recorda: visitar el passat no és el mateix que fer retrocedir la branca.
